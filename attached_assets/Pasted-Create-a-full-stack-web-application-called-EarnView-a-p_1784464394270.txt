Create a full-stack web application called "EarnView" — a professional rewards platform where users can earn points/money by completing sponsored tasks, watching approved promotional videos, and engaging with the platform.

The platform should be designed like a modern fintech/rewards application with a clean, trustworthy, mobile-friendly interface.

TECHNOLOGY STACK:
- Frontend: React + Tailwind CSS
- Backend: Node.js + Express
- Database: PostgreSQL
- Authentication: Secure email/password authentication
- Use modern UI components and responsive design

BRAND DESIGN:
Create a professional design using:
- White background
- Blue primary colors
- Green colors for rewards, success, and earnings
- Clean typography
- Modern cards
- Smooth animations
- Mobile-first interface
